## Бот
Четыре сценария подарков: первые три реплики — анекдот и ответ GigaChat с тематической связкой; четвёртая — уход в Одессу и кнопка сайта. Ответы на утверждения включены. Тайм-аут GigaChat 1.5 секунды с резервным ответом.
Капитан talk: сало и приветствие → по сообщениям гостя три пхринципа с фото и задержкой 2 секунды → кнопка сайта → джин с шоколадом → пиратский финал.
Кофе: «Извини, дорогой, дизайн сайта пока именинник не согласовал. А пока — чашечку кофе!»
Уход: «Вы не просили песен — они есть у меня, а запас анекдотов и провизии нужно пополнять. Я в Одессу, а вы пока на сайт СК Инкоррос: там вам покажут не только где раки зимуют, но и как для них делают настоящую качественную кровлю. Хорошая крыша, как хорошая жена, должна быть надёжной и не течь.»

## Запуск и ограничения
Windows: C:\Users\ikash\max-assistant. Ctrl+C, затем:
git fetch origin vh-birthday-2026
git checkout FETCH_HEAD -- birthday_bot.py
.\START_BIRTHDAY_BOT.cmd
Не использовать git checkout origin/vh-birthday-2026 -- birthday_bot.py.
Одновременно один polling-процесс. Маршрут подключения проверить при переносе: не копировать Windows localhost-прокси на сервер. Токены только в переменных окружения, не в Git.
Исправлено обрезание кода изображений; файл бота уменьшен и повторно прочитан с GitHub. Автоматические проверки не заменяют живую проверку Windows/Telegram.
Сайт отвечает HTTP 200; последняя публикация проверена. Проверка во всех браузерах не проведена. Реальная работа актуального бота и все переходы после последнего обновления пользователем пока не подтверждены.
